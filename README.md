# The Imperial Palace Rajkot

A premium 5-star luxury hotel website demo built with React + Vite + TypeScript.

## Tech Stack

- **React 19** + **Vite** + **TypeScript**
- **Tailwind CSS 4** — ivory/charcoal/muted-gold luxury theme
- **motion/react** (Framer Motion v12) — smooth animations & reveal effects
- **React Router v7** — declarative routing
- **Cormorant Garamond** serif + **Geist** sans — premium typography

## Pages

| Route | Page |
|-------|------|
| `/` | Homepage (10 sections) |
| `/stay` | Rooms & Suites listing |
| `/stay/:slug` | Room Detail + Booking Modal |
| `/dining` | Dining venues |
| `/weddings` | Wedding planning |
| `/events` | Events & Banquets |
| `/wellness` | Wellness & Spa |
| `/experiences` | Hotel experiences |
| `/tour` | 360° Virtual Tour |
| `/gallery` | Photo Gallery |
| `/contact` | Contact & Enquiry |

## Key Features

- Static frontend only — no backend, no auth, no payments
- All data in `src/lib/hotel-data.ts` for easy CMS swap
- Mobile-responsive with mobile nav drawer
- Fullscreen gallery lightbox with prev/next
- Static enquiry modals with demo success state
- Floating WhatsApp + Book Stay buttons
- 360° tour with clickable hotspot navigation
